# Bookings Data Analysis Dashboard

## Project Overview
This project analyzes ride-booking data to understand booking performance, cancellation patterns, vehicle preferences, ride volume, customer ratings, and booking value.

The project uses Microsoft Excel, MySQL, and Power BI to clean data, perform SQL analysis, and build dashboards for business insights.

## Project Objectives
- Analyze total bookings and booking status.
- Understand customer and driver cancellation patterns.
- Compare bookings across vehicle types.
- Analyze ride volume and booking value.
- Explore payment methods and customer ratings.
- Identify trends in incomplete rides.
- Present insights through interactive dashboards.

## Tools & Technologies
- **Microsoft Excel:** Data cleaning, PivotTables, charts, and dashboard creation.
- **MySQL:** SQL queries, aggregations, joins, subqueries, and other analysis techniques used in the project.
- **Power BI:** Data modeling, DAX measures, and interactive dashboard development.

## Project Workflow
1. Reviewed the original bookings dataset.
2. Cleaned and prepared the data in Excel.
3. Performed data analysis using MySQL.
4. Created an Excel dashboard.
5. Built an interactive Power BI dashboard.
6. Analyzed booking trends and cancellation patterns.
